🍽️ Ordered Items List Web App

📌 Overview

This is a simple web application that dynamically displays a list of ordered food items. Users can remove any item from the list by clicking the "Cancel" button. The project is built using HTML, CSS, Bootstrap, and JavaScript.



🚀 Features

* 📋 Displays ordered items dynamically
* ❌ Remove items with a Cancel button
* ⚡ Real-time DOM updates
* 🎯 Beginner-friendly project for learning JavaScript

🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript (DOM Manipulation)

 📂 Project Structure

```
├── index.html
├── styles.css
├── script.js
```

▶️ How It Works

* A predefined list of food items is stored in JavaScript
* Items are dynamically added to the page using DOM methods
* Each item has a "Cancel" button
* Clicking the button removes the item from the list

📸 Output

* Displays a heading: **"Your Ordered Items"**
* Shows a list of food items (Veg Biryani, Chicken 65, Paratha)
* Each item has a Cancel button to remove it

🎯 Learning Outcomes

* Creating elements dynamically using JavaScript
* Using `appendChild()` and `createElement()`
* Handling button click events
* Updating UI in real-time

📌 Future Improvements

* Add new items dynamically
* Save items using Local Storage
* Add animations when removing items
* Improve UI design
